# Data Job Market Analysis Project

## Introduction
This project analyzes the data job market to identify high-value skills and salary trends for data professionals. The analysis focuses on data scientists, data engineers, and related roles to help job seekers understand which skills offer the best career opportunities.

## Background
With the rapid growth of data-related jobs, professionals need guidance on:
- Which skills are most valuable
- Salary expectations for different roles
- How skills correlate with earning potential
- Remote work opportunities in the field

This project uses real job posting data to provide data-driven insights for career planning.

## Tools I Used
- **PostgreSQL**: For database management and complex queries
- **SQL**: For data extraction and analysis
- **Git/GitHub**: For version control and sharing the analysis

## The Analysis
The project consists of four key analyses:

1. **[Top Remote Jobs Analysis:](https://github.com/Brtelfer/SQL_Data_Projects/blob/SQL_Project/project_sql/1_highest_paying_jobs.sql)**
   - Identifies highest-paying remote positions for data professionals
   - Shows company names and salary information

2. **[Skills for Top-Paying Jobs:](https://github.com/Brtelfer/SQL_Data_Projects/blob/SQL_Project/project_sql/2_highest_paying_skills.sql)**
   - Reveals which skills are required for the 10 highest-paying remote jobs
   - Helps professionals target skill development

3. **[Most Demanded Skills:](https://github.com/Brtelfer/SQL_Data_Projects/blob/SQL_Project/project_sql/3_high_demand_skills.sql)**
   - Analyzes which skills appear most frequently in Data Analyst job postings
   - Shows the top 5 most requested skills

4. **[Salary-Skill Correlations:](https://github.com/Brtelfer/SQL_Data_Projects/blob/SQL_Project/project_sql/4_skill_by_salary.sql)**
   - Breaks down skills by salary ranges
   - Identifies which skills cluster in higher salary brackets

5. **[Optimal Skills Analysis:](https://github.com/Brtelfer/SQL_Data_Projects/blob/SQL_Project/project_sql/5_optimal_skills.sql)**
   - Combines salary and demand metrics
   - Scores and tiers skills based on market value

## What I Learned
Through this analysis, I discovered:

1. The highest-paying remote data jobs are concentrated in:
   - Senior Data Engineering roles
   - Specialized Data Scientist positions

2. The most valuable skills combine:
   - Technical capabilities (Python, Spark, AWS)
   - Data infrastructure knowledge (Kubernetes, Airflow)
   - Cloud platform expertise

3. Salary distribution shows:
   - Clear stratification by skill combinations
   - Significant premium for cloud and distributed systems skills

4. The "optimal skills" analysis revealed:
   - Elite skills command both high salaries and high demand
   - Some niche skills offer high pay but limited opportunities

## Conclusions
The analysis provides actionable insights for data professionals:

1. **For Career Starters**: Focus on high-demand skills like Python and SQL that appear across salary ranges
2. **For Mid-Career Professionals**: Invest in cloud platforms and data infrastructure skills to access higher salary brackets
3. **For Job Seekers**: Target remote opportunities in senior data engineering roles for top compensation
4. **For Learners**: Prioritize skills with both high salaries and strong demand (the "Elite" tier)

This project demonstrates how data analysis can provide concrete career guidance in the tech field. Future enhancements could include temporal analysis of skill trends and regional salary comparisons.
